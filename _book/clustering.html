15.1 Learning Objectives

By the end of this section, you will be able to:

  • Apply K-means, DBSCAN, and Hierarchical clustering.
  • Interpret common graphs.
  • Produce parallel coordinates plots for each clustering solution.
  • Compare cluster assignments to true Iris species.

15.2 Setup

Code 
library(tidyverse)
library(factoextra)
library(cluster)
library(dbscan)
library(NbClust)
library(GGally)   # for parallel coordinate plots
set.seed(4321)

15.3 Dataset

Code 
data(iris)
iris_num <- iris %>% select(where(is.numeric))
iris_scaled <- scale(iris_num)
head(iris_scaled)

15.3.1 Explanation

We extract the numeric features of the Iris dataset and scale them so that all variables contribute equally. Scaling is crucial because distance-based clustering is sensitive to variable magnitude.

15.4 PCA Visualization

Code 
pca <- prcomp(iris_scaled)
fviz_pca_ind(pca, geom="point", title="PCA Visualization of Iris")

15.4.1 Explanation

A PCA scatterplot allows us to see the structure of high-dimensional data in two dimensions. If clusters exist naturally, PCA often reveals them visually.

15.5 PART 1 — Determining k for K-means

15.5.1 Elbow Plot

Code 
fviz_nbclust(iris_scaled, kmeans, method="wss") +
  labs(title="Elbow Method (WSS vs k)")

15.5.1.1 Explanation

The elbow plot shows how total within-cluster variation decreases as k increases.
We select the k where improvement slows down — the “elbow.”

15.5.2 Silhouette Plot

Code 
fviz_nbclust(iris_scaled, kmeans, method="silhouette") +
  labs(title="Silhouette Method")

15.5.2.1 Explanation

The silhouette method evaluates how well-separated clusters are.
Higher values indicate clearer boundaries. The optimal k maximizes silhouette width.

15.5.3 Gap Statistic

Code 
set.seed(4321)
gap <- clusGap(iris_scaled, FUN=kmeans, nstart=25, K.max=10, B=30)
fviz_gap_stat(gap)

15.5.3.1 Explanation

The gap statistic compares cluster dispersion to what would be expected if no clustering existed.
A large “gap” indicates strong underlying cluster structure.

15.5.4 NBClust

Code 
set.seed(4321)
nb_res <- NbClust(iris_scaled, distance="euclidean",
                  min.nc=2, max.nc=10, method="kmeans")
*** : The Hubert index is a graphical method of determining the number of clusters.
                In the plot of Hubert index, we seek a significant knee that corresponds to a 
                significant increase of the value of the measure i.e the significant peak in Hubert
                index second differences plot. 
 
*** : The D index is a graphical method of determining the number of clusters. 
                In the plot of D index, we seek a significant knee (the significant peak in Dindex
                second differences plot) that corresponds to a significant increase of the value of
                the measure. 
 
******************************************************************* 
* Among all indices:                                                
* 11 proposed 2 as the best number of clusters 
* 10 proposed 3 as the best number of clusters 
* 1 proposed 4 as the best number of clusters 
* 1 proposed 6 as the best number of clusters 
* 1 proposed 10 as the best number of clusters 

                   ***** Conclusion *****                            
 
* According to the majority rule, the best number of clusters is  2 
 
 
*******************************************************************
Code 
best_k <- nb_res$Best.nc[1]
best_k
[1] 3
Code 
vote_dist <- as.data.frame(table(nb_res$Best.nc[1, ]))

ggplot(vote_dist, aes(Var1, Freq)) +
  geom_col(fill="steelblue") +
  labs(title="NbClust: Votes for k")

15.5.4.1 Explanation

NBClust computes 30+ indices to recommend the number of clusters.
We visualize the vote distribution and use the majority vote.

15.6 K-means Clustering

Code 
kmeans_fit <- kmeans(iris_scaled, centers = best_k, nstart=30)
fviz_cluster(kmeans_fit, iris_scaled,
             main=paste("K-means Clusters (k=", best_k, ")", sep=""))

15.6.1 Explanation

K-means partitions data into spherical clusters using centroids.
The PCA visualization shows how those clusters look in reduced space.

15.7 Compare K-means to True Species

Code 
table(KMeans = kmeans_fit$cluster, Species = iris$Species)
      Species
KMeans setosa versicolor virginica
     1      0         39        14
     2     50          0         0
     3      0         11        36

15.7.1 Explanation

This table shows how well K-means clusters match the true species.
K-means typically identifies Setosa perfectly but overlaps Versicolor and Virginica.

15.8 Parallel Coordinates for K-means

Code 
iris_km <- iris_num %>% mutate(Cluster = factor(kmeans_fit$cluster))
GGally::ggparcoord(iris_km, columns = 1:4, groupColumn = "Cluster",
                   title="Parallel Coordinates: K-means Clusters")

15.8.1 Explanation

Parallel coordinate plots show variable profiles across clusters.
K-means clusters should show distinct shape patterns if clustering is meaningful.

15.9 PART 2 — Hierarchical Clustering

15.9.1 Dendrogram

Code 
d <- dist(iris_scaled)
hc_complete <- hclust(d, method="complete")
fviz_dend(hc_complete, k=3, rect=TRUE,
          main="Hierarchical Clustering (Complete Linkage)")

15.9.1.1 Explanation

Hierarchical clustering builds a tree structure showing merging of points/clusters.
Cutting the dendrogram at height = 3 yields three clusters.

15.9.2 Cut into 3 Clusters and Compare

Code 
hc_clusters <- cutree(hc_complete, k=3)
table(Hierarchical = hc_clusters, Species = iris$Species)
            Species
Hierarchical setosa versicolor virginica
           1     49          0         0
           2      1         21         2
           3      0         29        48

15.9.2.1 Explanation

Hierarchical clustering does not require pre-specifying k — we “cut” the dendrogram.
This table shows how hierarchical groupings align with real species.

15.9.3 PCA Visualization of Hierarchical Clusters

Code 
fviz_cluster(list(data=iris_scaled, cluster=hc_clusters),
             geom="point",
             main="Hierarchical Clusters (k=3)")

15.9.3.1 Explanation

A PCA scatterplot shows how hierarchical clusters spread in low-dimensional space.
Complete linkage tends to produce compact clusters.

15.9.4 Parallel Coordinates for Hierarchical

Code 
iris_hc <- iris_num %>% mutate(Cluster = factor(hc_clusters))
GGally::ggparcoord(iris_hc, columns = 1:4, groupColumn = "Cluster",
                   title="Parallel Coordinates: Hierarchical Clusters")

15.9.5 Explanation

Parallel coordinates allow us to compare variable patterns across hierarchical clusters.

15.10 PART 3 — DBSCAN

15.10.1 kNN Distance Plot

Code 
minPts <- 2 * ncol(iris_scaled)
kNNdistplot(iris_scaled, k=minPts)
abline(h=0.9, lty=2)

15.10.1.1 Explanation

The kNN plot helps choose eps by showing the distance to each point’s k-th neighbor.
The “knee” in the curve is the suggested eps threshold.

15.10.2 Fit DBSCAN

Code 
db_fit <- dbscan(iris_scaled, eps=0.9, minPts=minPts)
db_fit
DBSCAN clustering for 150 objects.
Parameters: eps = 0.9, minPts = 8
Using euclidean distances and borderpoints = TRUE
The clustering contains 2 cluster(s) and 7 noise points.

 0  1  2 
 7 48 95 

Available fields: cluster, eps, minPts, metric, borderPoints

15.10.2.1 Explanation

DBSCAN groups high-density regions and labels low-density points as noise (cluster 0).

15.10.3 DBSCAN Clusters in PCA Space

Code 
fviz_cluster(list(data=iris_scaled, cluster=db_fit$cluster),
             geom="point",
             ellipse.type="convex",
             main="DBSCAN Clusters")

15.10.3.1 Explanation

DBSCAN finds arbitrary-shaped clusters that density-based methods capture better than K-means.

15.10.4 Compare DBSCAN to True Species

Code 
table(DBSCAN = db_fit$cluster, Species = iris$Species)
      Species
DBSCAN setosa versicolor virginica
     0      2          1         4
     1     48          0         0
     2      0         49        46

15.10.4.1 Explanation

DBSCAN often segments Setosa well but may merge Versicolor and Virginica depending on eps.

15.10.5 Parallel Coordinates for DBSCAN

Code 
iris_db <- iris_num %>% mutate(Cluster = factor(db_fit$cluster))
GGally::ggparcoord(iris_db, columns = 1:4, groupColumn = "Cluster",
                   title="Parallel Coordinates: DBSCAN Clusters")

15.10.5.1 Explanation

Parallel coordinates show how DBSCAN clusters differ in variable space and highlight noise points.
